# Python tooling for the KiCad side of this project.
#
# The venv MUST be created with --system-site-packages, because `pcbnew` ships
# with KiCad itself and is not installable from PyPI:
#
#     /usr/bin/python3 -m venv --system-site-packages .venv-kicad
#     .venv-kicad/bin/pip install -r requirements.txt
#
# .venv-kicad/ is gitignored, so this file is the only record of what goes in it.

# Transitive: kicad-skip's parser. Pinned because it is what was tested.
